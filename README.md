# Programming for DS

A Python project for learning and practicing programming concepts used in data science.

## Requirements

- Python 3.14 or newer
- [uv](https://docs.astral.sh/uv/)

## Setup

Clone the repository and install its environment and dependencies:

```bash
uv sync
```

## Usage

Run the project with:

```bash
uv run programming-for-ds
```

## Development

The package uses a `src/` layout. Add dependencies with `uv add` and run project commands through `uv run` so they use the managed environment.
